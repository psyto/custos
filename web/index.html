Solana execution firewall — see what a transaction does to your accounts before you sign.

Each transaction below is simulated against real mainnet state. A balance-diff scanner judges safety by whether tokens move. Custos judges by the post-simulation state of the accounts you control — so it catches approvals and authority changes that move zero balance in the transaction yet hand an attacker future control.

Live pre-sign firewall

Connect a wallet, then let a malicious dApp hand you a transaction. Custos simulates the exact tx against current mainnet state before Phantom is ever asked to sign. On a RED verdict, signing is blocked — the wallet is never prompted.

Verdicts are produced live by the Custos engine (GET /api/demo). Benign real swaps scan GREEN via cargo run --bin scan; a real account × prospective drainer scans RED via cargo run --bin live_red. This screen is the wallet-facing surface over that engine.
