# Custos — agent-payment demo video

Animated terminal of the agent/solver pre-broadcast gate (the real `agent_demo`
hero output): declared-intent authorization PASS → Custos re-execution RED (F2) →
REFUSE TO BROADCAST. 30s, 1280x720, for build-in-public / outreach.

```bash
npm install
npm run record   # → custos-agent-demo.mp4  (needs ffmpeg on PATH)
```

`demo.html` is self-contained (no external assets); `record.js` drives headless
Chromium via Puppeteer + puppeteer-screen-recorder. Output mp4 is gitignored.
